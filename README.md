# Last One Standing

A polished, text-first battle royale simulator. Build a roster of custom contenders, equip them, tune the simulation, and watch an original story unfold round by round.

Contenders, custom weapons, custom events, and uploaded portraits are automatically saved in browser storage. Your arena is restored when you return or refresh the page.

## Development

```bash
npm install
npm run dev
```

Run the production checks with `npm test`, `npm run build`, and `npm run lint`.
